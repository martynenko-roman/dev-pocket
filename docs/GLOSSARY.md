# Glossary

| Term | Meaning |
| --- | --- |
| DevPocket | The app |
| Keep Awake | Prevent idle display sleep, but not lid-close sleep |
| Duration | 15 minutes, 1 hour, 2 hours, or Until turned off |
| Hidden | Show hidden files in Finder |
| Desktop | Show desktop icons |
| Dark | Use dark mode |
| Dock | Hide the Dock automatically |
| Output / Input | The default sound output / input device |
| Reverse mouse scroll direction | Reverse physical wheel deltas while leaving continuous gestures alone |
| Open at login | Launch DevPocket when signing in |
| Shortcuts | Optional global keyboard combinations, with no defaults |
